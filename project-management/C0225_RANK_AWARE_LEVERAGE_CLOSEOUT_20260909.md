# C0225 — Rank-aware Differential Opportunity / Leverage Decision-Control

Date: 2026-09-09 (Dubai)
Status: Completed / Verified

## Purpose

Add rank-aware game theory downstream of forecasting and squad optimization without contaminating expected-points estimates. Ownership is context, never proof of player quality.

## Production contract

Runtime: `EDGE_FUNCTION:fpl-decision-control:v2`
Decision-control version: `C0225_RANK_AWARE_LEVERAGE_V01`
Append-only evidence: `public.fpl_decision_control_runs`

C0225 calls the canonical full-pool optimizer and then enriches only decisions already returned by that optimizer. It does not change model predictions or objective values.

### Hard invariants

- `numeric_xpts_adjustment=false`.
- `forced_differential=false`.
- Rank never widens the fixed model-error band in V01.
- ROLL remains the baseline.
- Current ownership source is `players.selected_by_percent`, explicitly treated as an ownership proxy rather than effective ownership.
- Captaincy is not forced by ownership.
- Historical forecasts are never rewritten.

## Differential qualification

A player is eligible for leverage classification only when all structural gates pass:

- expected minutes >= 60;
- start probability >= 0.55;
- P(10+) >= 0.09;
- no control/defensive-role risk for an FPL MID/FWD unless primary penalty responsibility removes that role-risk condition upstream.

Ownership tiers:

- <= 5%: `EXPLOSIVE_DIFFERENTIAL`;
- <= 10%: `DIFFERENTIAL`;
- <= 15%: `SEMI_DIFFERENTIAL`.

Continuous leverage diagnostic:

`scarcity × haul-tail signal × minutes/start/role reliability`

with haul-tail signal based on P(10+), P(15+) and P(20+). This is a Decision-Control diagnostic only; it is not added to xPts.

## Known limitation intentionally deferred

C0225 V01 can only adjudicate squad structures already returned by the canonical optimizer. It does not itself generate diverse near-optimal squads and therefore cannot discover an alternative structure that the optimizer never exposed. That limitation is addressed by the C0226 autonomous-decision architecture program, especially the ensemble/equivalence-class search layer.
