# C0194 / C0195 — Historical FPL and Global Finished-Prediction Audit Closure

Date: 2026-09-03

## Scope

This record closes two user-facing truthfulness requirements in UI v2 without changing any historical forecast, model probability, betting call, FPL projection, or experiment state.

- **C0194 — Historical FPL decisions and explicit prediction audit markers**
- **C0195 — Global finished-prediction audit markers**

The governing presentation invariant is now:

> For any finished event with a known outcome, every displayed settleable prediction must carry an explicit accessible **✓** when correct or **×** when wrong. Upcoming or unsettled events show no result mark.

## C0194 — Historical FPL decision truth

Historical FPL pages now render the original frozen decision snapshot when available instead of reconstructing history from the current model or an empty current manager-plan state.

Where an actual manager action was recorded after the Gameweek, it is displayed as a separate overlay and never overwrites the frozen model decision.

Finished Fixture cards also expose explicit prediction audit marks for the displayed 1X2 call and most-likely exact score, including cases where the original call state was `No clear edge` but a top outcome still existed.

Performance remains human-facing: internal A0005 / variant identifiers are not exposed as decision-facing language.

## C0195 — Global finished-prediction audit invariant

Prediction settlement was centralized rather than implemented as a Markets-only special case.

Shared settlement logic now supports:

- 1X2
- exact score
- Over / Under 2.5
- BTTS Yes / No

The shared accessible audit marker is reused by Fixtures and Betting/Markets. Markets' four strongest model calls therefore settle visibly after the associated event is finished, using the actual final score from the matching fixture. This does not depend on bookmaker-price diagnostics being present.
